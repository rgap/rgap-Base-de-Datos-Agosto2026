\begin{frame}{El curso prepara para diseñar y gestionar bases de datos relacionales}
\begin{columns}[c,onlytextwidth]
\column{.56\textwidth}
\begin{block}{Logro general de aprendizaje}
\small Al finalizar el curso, el estudiante aplica técnicas de diseño y manipulación de bases de datos estructuradas para gestionar información, utilizando SQL y considerando criterios de integridad y normalización de datos.
\end{block}
\begin{exampleblock}{Naturaleza del curso}
\small El curso es práctico: integra modelamiento y diseño de datos, definición y manipulación de objetos con SQL, y nociones de administración de bases de datos.
\end{exampleblock}
\column{.40\textwidth}
\small
\begin{tabular}{>{\bfseries}p{1.65cm}p{3.0cm}}
\toprule
Carreras & Sistemas e Informática / Software\\
\midrule
Créditos & 3\\
Modalidad & Virtual en vivo\\
Horas & 4 semanales\\
\bottomrule
\end{tabular}
\end{columns}
\end{frame}

% 4 ---------------------------------------------------------------------
\begin{frame}{La práctica avanza del modelo de datos a su administración}
\begin{columns}[T,onlytextwidth]
\column{.32\textwidth}
\begin{block}{Unidad 1}
\footnotesize
\begin{itemize}\setlength\itemsep{2pt}
  \item Conceptos de BD relacionales
  \item Diseño conceptual, lógico y físico
  \item Modelo E--R y tipos de relaciones
  \item Claves, dependencias y normalización
\end{itemize}
\end{block}
\column{.32\textwidth}
\begin{exampleblock}{Unidad 2}
\footnotesize
\begin{itemize}\setlength\itemsep{2pt}
  \item DDL y DML
  \item Consultas y vistas
  \item JOIN e índices
  \item Agregaciones, subconsultas y funciones
\end{itemize}
\end{exampleblock}
\column{.32\textwidth}
\begin{alertblock}{Unidad 3}
\footnotesize
\begin{itemize}\setlength\itemsep{2pt}
  \item Funciones, variables y cursores
  \item Procedimientos, transacciones y triggers
  \item Backups, seguridad, usuarios y roles
  \item SQL frente a NoSQL
\end{itemize}
\end{alertblock}
\end{columns}
\vspace{0.2cm}
\small Cada semana combina exposición docente con ejercicios de modelamiento, consultas SQL y administración.
\end{frame}
