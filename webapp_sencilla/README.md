# Agenda: mi primera webapp con SQL

## Cómo abrirla

1. Abre una terminal dentro de esta carpeta.
2. Escribe `npm install` (solo la primera vez).
3. Escribe `npm run dev`.
4. Entra en el navegador a <http://localhost:3000>

## Qué hace

Cuando entras a la página, se ejecuta este SQL:

```sql
SELECT * FROM contacto
```

y verás sus filas en el navegador.

## Prueba

Cambia el SQL en `app.js`, guarda y recarga el navegador.
